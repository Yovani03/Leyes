# Documentos de origen

Todo el contenido del sitio sale de los análisis que presentaron los compañeros. Los archivos
originales (algunos pesan decenas de MB) **no se suben al repositorio**; están en `.gitignore`.

Si quieres consultarlos desde el repo, copia los archivos aquí, dentro de `docs/originales/`
(esa carpeta también está ignorada por Git).
